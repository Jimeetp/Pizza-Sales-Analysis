# 🍕 Pizza Sales Analysis | SQL + Power BI

End-to-end analysis of a pizza restaurant's 2015 sales: Excel data → SQL KPIs → interactive Power BI dashboard.

![Home Dashboard](images/dashboard_home.png)
![Best and Worst Sellers](images/dashboard_best_worst.png)

## 📌 Problem Statement
The restaurant wants to understand its sales performance, ordering patterns and product popularity to make better menu, staffing and marketing decisions.

## 🛠️ Tools
Excel • SQL (MySQL) • Power BI

## 📊 KPIs (calculated in SQL)
| KPI | Value |
|-----|-------|
| Total Revenue | $817.9K |
| Average Order Value | 38.31 |
| Total Pizzas Sold | 49,574 |
| Total Orders | 21,350 |
| Avg Pizzas Per Order | 2.32 |

## 📈 Dashboard Includes
- Daily and monthly order trends
- % of sales by pizza category and size
- Total pizzas sold by category
- Top 5 and Bottom 5 pizzas by revenue, quantity and orders
- Filters for pizza category and date range

## 💡 Key Insights
- **Friday** is the busiest day; **Sunday** is the slowest.
- Peak order times are **12–1 PM** and **5–8 PM**.
- **Classic** is the top category (26.9% of sales, 14,888 pizzas sold).
- **Large** pizzas bring in the most sales (45.9%).
- Best seller by revenue: **The Thai Chicken Pizza**; by quantity and orders: **The Classic Deluxe Pizza**.
- Worst seller on all measures: **The Brie Carre Pizza**.
